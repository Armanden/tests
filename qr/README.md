# QR Code Reader & Generator

A comprehensive Java application for scanning, decoding, and generating QR codes using ZXing library.

## Features

✅ **Generate QR Codes**
- Encode any text into QR codes
- Custom dimensions support
- Multiple error correction levels
- UTF-8 character support

✅ **Scan & Decode QR Codes**
- Decode QR codes from image files
- Extract detailed QR code information
- Support for multiple code formats

✅ **User-Friendly CLI**
- Interactive menu-based interface
- Real-time feedback
- Comprehensive error handling
